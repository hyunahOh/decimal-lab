# decimal-lab

## 1. 무슨 역할을 하나요?

소수를 정수 기반으로 계산하는 TypeScript 라이브러리입니다. 사칙연산, 비교, 반올림, 거듭제곱, 제곱근과 문자열 출력을 지원합니다.

big.js 방식으로 메서드를 연결해 사용할 수 있습니다. 내부 속성 `c/e/s`의 직접 접근은 호환 범위에서 제외합니다.

```ts
import Big from "./src/index";

Big("0.1").plus("0.2").toString(); // "0.3"
Big("1").div("8").toFixed(2); // "0.13"
```

## 2. 어떤 원리로 동작하나요?

소수를 정수 `coefficient`와 소수점 위치 `scale`로 나눠 저장합니다.

```text
값 = coefficient × 10^(-scale)
12.34 = 1234 × 10^(-2)
```

- 정수값의 절댓값이 `10^15` 미만이면 Number 정수인 `small`, 그 이상이면 BigInt인 `big`으로 저장합니다.
- 덧셈·뺄셈은 scale을 맞춘 뒤 정수끼리 계산합니다. 곱셈은 정수값을 곱하고 scale을 더합니다.
- Number로 정확하게 계산할 수 없는 경우 원래 정수값을 BigInt로 변환해 계산합니다. 나눗셈과 제곱근은 지정한 자릿수와 반올림 규칙을 적용합니다.
- 자주 쓰는 10의 거듭제곱을 캐시하고, 반복적인 문자열 변환과 인수 복제를 줄여 연산 비용을 낮춥니다.
- 연산은 입력을 수정하지 않고 새 결과 객체를 반환합니다.

## 3. 성능 비교

Apple M2 · Node.js 24.14 · big.js 7.0.1 · decimal.js 10.6.0 기준입니다.
각 라이브러리를 약 10분씩 측정한 5회 중앙값이며, 단위는 **μs/회**입니다. 작을수록 빠릅니다.
장기 측정은 ES2022 출력 기준이고, 현재 프로젝트의 출력 타깃은 ES2020입니다.

나눗셈은 소수 20자리·HALF_EVEN으로 맞췄으며 decimal.js의 동일 출력 보정 비용도 포함합니다.
전체 흐름은 `Big(a).plus(b).times("1.1").div("3").toFixed(2)`입니다.
